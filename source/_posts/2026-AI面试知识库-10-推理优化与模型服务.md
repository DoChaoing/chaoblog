> **TL;DR** — 推理优化关注 TTFT、tokens/s、吞吐、显存和成本。核心技术包括 KV Cache、PagedAttention、Continuous Batching、量化、FlashAttention、投机解码和 LLM Gateway。

AI 应用上线后，模型推理常常是最大瓶颈和最大成本项。

---

## 1. Prefill 与 Decode

- Prefill：处理输入 prompt；
- Decode：逐 token 生成。

长 prompt 会拖慢首字，长输出会拖慢总耗时。

---

## 2. 核心优化技术

| 技术 | 作用 |
|:--|:--|
| KV Cache | 避免重复计算历史上下文 |
| PagedAttention | 高效管理 KV Cache 显存 |
| Continuous Batching | 动态合批提高吞吐 |
| 量化 | 降低显存和成本 |
| FlashAttention | 优化 Attention IO |
| Speculative Decoding | 小模型草稿，大模型验证 |

---

## 3. 推理框架

| 框架 | 定位 |
|:--|:--|
| vLLM | 高吞吐服务 |
| SGLang | 结构化生成和复杂 LLM 程序 |
| TensorRT-LLM | NVIDIA 极致性能 |
| TGI | Hugging Face 生态 |
| llama.cpp / Ollama | 本地和轻量部署 |

选型要看：吞吐、延迟、结构化输出、GPU 类型、模型支持和运维能力。

---

## 4. LLM Gateway

LLM Gateway 统一治理模型访问：

- 多模型路由；
- 限流；
- 计费；
- 缓存；
- A/B 测试；
- fallback；
- prompt 版本；
- 审计日志。

它是 AI 平台工程师高频系统设计题。
