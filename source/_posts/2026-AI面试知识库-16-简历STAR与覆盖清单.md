## 1. 简历写法

不要写：

```text
熟悉 LangChain、Milvus、FastAPI。
```

要写：

```text
设计并实现企业知识库 RAG 服务，负责文档 ETL、混合检索与流式问答；通过语义分块、BM25+向量融合和 reranker，将自建评测集 Recall@5 从 X 提升到 Y，并接入 trace 方便线上排障。
```

---

## 2. STAR 故事

至少准备 5 个：

- RAG 召回率优化；
- Agent 死循环治理；
- 工具调用安全；
- Token 成本控制；
- 线上故障排查。

每个故事按：

```text
Situation -> Task -> Action -> Result
```

但不要机械背稿，要记结构和关键词。

## 4. 没有逐字搬运的内容

没有直接放进博客的内容：

- 两个仓库里的完整 300+ 问答全文；
- 大段代码示例；
- 简历 HTML 模板；
- 漫画图片；
- 三语言项目 README 的完整命令细节；
- 个别实时版本动态和榜单细节。

原因：博客负责建立复习框架和表达路径，原仓库负责保留完整题库和模板。
