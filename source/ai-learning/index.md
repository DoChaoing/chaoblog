> 这是一套面向“能做 AI 应用、能讲清项目、能准备面试”的学习手册。题库和开源资料都保留，但不要从题库开始读，先按下面这条主线走。

## 先看这条主线

```text
LLM 基础
  -> Prompt 控制输出
  -> RAG 接入知识
  -> Agent 调用工具
  -> 工程化上线
  -> 项目表达
```

这条线只解决一个问题：从“会用模型”走到“能交付一个 AI 应用”。

## 你应该怎么读

1. 先读 7 篇主线文档，建立完整框架。
2. 每读一篇，都做一个小产出，不要只收藏概念。
3. 主线读完后，再回到题库查细节和面试追问。
4. 所有知识尽量落到同一个项目：企业知识库 RAG + Agent。

## 一条项目线贯穿到底

建议只做一个主项目，然后逐步升级：

```text
V1 文档问答
V2 混合检索和重排
V3 引用来源和结构化输出
V4 工具调用和 Agent 循环
V5 评测集、日志、成本统计
V6 简历描述和面试讲稿
```

这样学习不会散。每个知识点都能回答三个问题：

- 它解决项目里的什么问题？
- 它失败时会出现什么现象？
- 面试时怎么讲取舍和指标？

## 四周学习计划

**第 1 周：基础和 Prompt**

读 01、02、03。产出一张知识地图、三套 Prompt 模板、一个结构化输出 Demo。

**第 2 周：RAG**

读 04。做一个最小知识库问答系统，支持文档分块、Embedding、检索、引用来源和 20 条评测问题。

**第 3 周：Agent**

读 05。给项目加工具调用、最大轮数、状态记录、错误处理和 trace 日志。

**第 4 周：工程化和面试**

读 06、07。补上模型路由、限流、成本统计、bad case 回归，再写简历 bullet 和 3 分钟项目讲稿。

## 最终要留下什么

学完以后，不是留下几十篇收藏，而是留下 6 个可以展示的成果：

- 一张 AI 应用知识地图；
- 一个 RAG + Agent 项目；
- 一套 Prompt 模板；
- 一组评测 bad case；
- 一份项目架构图；
- 一段 3 分钟项目讲稿。
