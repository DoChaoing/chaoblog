> 这是一套重新整理后的 AI 学习文档，从基础概念到项目实战，再到面试表达。目标不是堆资料，而是让读者按顺序建立知识体系、做出项目、讲清能力。

## 学习主线

```text
AI 基础
  -> Prompt
  -> RAG
  -> Agent
  -> 工程化
  -> 项目实战
  -> 面试表达
```

## 学完要得到什么

| 成果 | 说明 |
|:--|:--|
| 一张 AI 知识地图 | 能说明 LLM、Prompt、RAG、Agent、工程化之间的关系 |
| 两个核心项目 | 一个 RAG 知识库，一个 Agent 助手 |

## 六周节奏

| 周期 | 学习内容 | 产出 |
|:--|:--|:--|
| 第 1 周 | AI 基础 + Prompt | 调通模型调用，完成结构化输出 |
| 第 2-3 周 | RAG | 做出带引用来源的知识库问答 |
| 第 4 周 | Agent | 做出工具调用型 AI 助手 |
| 第 5 周 | 工程化 | 补评测、日志、成本、安全和部署 |
| 第 6 周 | 项目与面试 | 整理作品集、简历和项目讲稿 |

## 怎么学

每篇文章都按这个顺序使用：

1. 先读“要解决的问题”；
2. 再做“最小实操任务”；
3. 记录“失败案例和优化方式”；
4. 最后整理“面试怎么讲”。

判断自己是否学会，不看记了多少概念，而看能不能完成这些动作：

- 能解释 LLM 的上下文、Token、幻觉和能力边界；
- 能写出稳定的 Prompt，并让输出结构化；
- 能做一个可引用来源的 RAG 知识库；
- 能做一个带工具调用、记忆和日志的 Agent；
- 能说明评测、成本、部署和安全方案；
- 能把项目写进简历，并在面试中讲清楚。
