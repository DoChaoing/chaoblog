这里不是 AI 名词大全，而是一张按目标组织的学习地图。先完成一个能运行、能解释、能验证的小成果，再进入更复杂的 RAG、Agent 和部署系统。

## 第一步：选择你的目标

- **想快速做出 AI 应用**：从 [Python 新手学 AI：7 个两天内能做完的开源项目](/2026/08/11/2026-Python新手可上手的开源AI项目/) 开始；
- **想系统理解大模型**：阅读 [零基础学大模型：8 周开源项目路线](/2026/08/10/2026-从0到1学习大模型-开源路线图/)；
- **想筛选可靠资料**：查看 [大模型学习资料推荐：从入门、RAG 到推理部署](/2026/08/10/2026-大模型优质学习资料库/)；
- **目标是求职或转岗**：进入 [AI 面试准备](/interview/)。

## 第二步：按照能力递进

| 阶段 | 学习重点 | 应留下的成果 |
|:--|:--|:--|
| AI 入门 | 模型调用、Prompt、结构化输出 | 一个有错误处理的小工具 |
| 应用工程 | Gradio、FastAPI、日志与测试 | 一个可调用、可测试的 API |
| RAG | 切分、检索、重排序、引用与评测 | 一组问题集和可溯源回答 |
| Agent | 工具调用、权限、超时与状态 | 一份完整可审计的执行记录 |
| 推理部署 | 延迟、吞吐、显存、量化与并发 | 可复现的压测报告 |

## 学习原则

- 优先阅读官方文档、论文作者代码和活跃开源项目；
- 每次学习都留下运行命令、输入输出和失败记录；
- 遇到新框架，先写出希望验证的收益；
- 不以安装数量、模型参数量或成功截图作为成果。
