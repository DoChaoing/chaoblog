这里不提供一张需要全部完成的知识地图。先选一个目标，完成一个能运行、能解释、能验证的小成果，再决定下一步。

## 你现在想完成什么

### 路线 A：做出第一个 AI 应用

适合会写一点 Python，希望尽快建立工程手感的读者。

1. 阅读 [Python 新手学 AI：7 个两天内能做完的开源项目](/2026/08/11/2026-Python新手可上手的开源AI项目/)；
2. 选择一个项目，只实现文中定义的最小成果；
3. 写下输入、输出、失败情况和复现命令；
4. 再进入 RAG 或受限工具调用。

完成标准：不是“页面能聊天”，而是另一个人按照说明能够运行并验证结果。

### 路线 B：理解模型为什么能生成文本

适合希望理解 tokenizer、attention、训练循环和评测的人。

1. 阅读 [零基础学大模型：8 周开源项目路线](/2026/08/10/2026-从0到1学习大模型-开源路线图/)；
2. 从 tokenizer 和 attention 小实验开始；
3. 完成一次小模型训练闭环；
4. 保留数据、配置、损失曲线和评测记录。

完成标准：能够解释一次训练实验改了什么，以及结果为什么变好或变差。

### 路线 C：关注推理与部署

适合后端、平台或基础设施方向的开发者。

1. 先区分首字延迟、吞吐量、并发和显存占用；
2. 使用同一个模型、同一组输入建立测试基线；
3. 再比较 Ollama、llama.cpp 或 vLLM 等方案；
4. 记录硬件、版本、参数和原始结果。

这条路线正在建设，当前可以先查看 [大模型学习资料推荐：从入门、RAG 到推理部署](/2026/08/10/2026-大模型优质学习资料库/) 中的评测与部署部分。
