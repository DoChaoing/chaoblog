## 02 · 可靠 RAG 系统｜建设中

目标：构建一个能够引用来源、接受评测并说明失败原因的知识库系统。

计划顺序：

```text
最小检索实现
  -> 文档切分与 Embedding
  -> 混合检索与重排序
  -> 引用溯源
  -> 自动评测
  -> API、部署与压测
```

## 03 · 可控 Agent｜建设中

目标：理解工具调用循环，并处理权限、超时、重试、状态恢复和可观测性。

重点不是“让 Agent 自己做一切”，而是明确它能做什么、什么时候停止，以及失败后如何恢复。

## 04 · 推理与部署｜建设中

目标：使用可重复的测试比较本地与服务端推理方案。

后续将围绕首字延迟、吞吐量、并发、显存、量化和批处理组织实验，并公开测试环境与原始结果。
